# 🗂️ Simple Kanban Board

A clean, minimal, and interactive Kanban board built with **HTML, CSS, and JavaScript**.  
Perfect for managing tasks, visualizing workflows, or learning DOM manipulation and drag-and-drop logic.

---

## 🚀 Live Demo  
👉 [View Demo](#) *(https://simple-kanban-board-omega.vercel.app/)*  

---

## 🧠 About the Project  
The **Simple Kanban Board** allows users to create, move, and organize tasks across different workflow stages such as:  
- **To-Do**  
- **In Progress**  
- **Done**  

It’s designed to be lightweight and dependency-free — everything runs right in the browser, with task persistence through **Local Storage**.

---

## ✨ Features  
✅ Create, edit, and delete tasks  
✅ Drag & drop tasks between columns  
✅ Auto-save board state locally  
✅ Responsive layout for desktop & mobile  
✅ Clean and customizable design  

---

## 🧱 Built With  
- **HTML5** – structure  
- **CSS3** – styling & layout  
- **JavaScript (ES6)** – logic and interactions  
- **Local Storage API** – data persistence
